Developers

Ten lines of client.
One socket forever.

  • Token auth on connect — sessions, not query-string secrets
  • Rooms as signed channel names, private by default
  • Automatic reconnect with exponential backoff + backfill
  • Works with Laravel Reverb, Ratchet, or any WS server you run
chat.js
const ws = new WebSocket('wss://echo.yourapp.com/app');

ws.onmessage = e => render(JSON.parse(e.data));

sendBtn.onclick = () => ws.send(JSON.stringify({
  room: 'team-echo',
  text: input.value
}));

// presence, typing, receipts: same socket, free.
